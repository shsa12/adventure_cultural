DISPARPORA CULTURAL ADVENTURE
Starter project website game edukasi DISPARPORA Kabupaten Sambas.

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka folder disparpora-cultural-adventure.
3. Buka index.html di browser untuk melihat landing page.
4. Untuk online, unggah seluruh isi folder ke repository GitHub.
5. Aktifkan GitHub Pages melalui Settings > Pages > Deploy from a branch > main > /(root) > Save.

YANG PERLU DIGANTI
1. Logo: letakkan logo resmi di assets/images/logo-disparpora.png. Untuk saat ini logo masih berupa huruf D.
2. Warna: sesuaikan variabel warna di bagian :root pada style.css setelah warna logo resmi diketahui.
3. Soal: buka js/quiz.js, lalu isi array questions mengikuti contoh format di dalam file.
4. Instagram: buka js/budaya.js, lalu ganti INSTAGRAM_URL dengan URL akun resmi dinas.
5. Mini game pencarian budaya: area pencarian masih placeholder, perlu ditambahkan gambar dan daftar objek yang dicari.

CATATAN
- Level 2 dan Level 3 masih berupa halaman Coming Soon.
- Konfirmasi Instagram adalah manual, bukan verifikasi otomatis status follow.
- Proyek ini merupakan starter yang bisa dikembangkan lebih lanjut.
